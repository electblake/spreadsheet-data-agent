# Processed Data — Project-Managed, Reproducible Output

Files in this directory are created and managed by the project from source inputs in `data/external/`. They are project-generated artifacts, not original customer files or user uploads.

- Agents and project tooling may create, edit, overwrite, rename, move, delete, and regenerate files in this directory as required by the project.
- Keep processed artifacts reproducible from the original inputs in `data/external/` and the project's code or documented procedures.
- Treat `data/external/` as read-only source data. Never modify external inputs while creating or regenerating processed artifacts.
- Do not place original customer files, uploads, or the only copy of any source data in this directory.
- Do not treat processed artifacts as a substitute for preserving the original external inputs.
